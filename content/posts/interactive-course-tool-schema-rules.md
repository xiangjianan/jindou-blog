这是一门**互动式课程**，用悬念、拖拽配对和动画教你给 Agent 写好工具 Schema——从「为什么 Agent 会静默失败」讲到 5 条可落地的 schema 设计规则。

**👉 [点击这里进入互动课程](/courses/tool-schema-rules/)**

4 个模块：
1. **静默失败之谜** — 44/61 prose 失败 vs 111/111 诚实报错的真实数据
2. **Schema 的解剖学** — 租房合同比喻：enum/pattern/format vs description 各管什么
3. **5 条规则逐条拆解** — 正反例 JSON 对照 + 应用 quiz
4. **从规则到习惯** — schema-lint 思维

含拖拽配对、群聊动画、数据流动画。源自我们的一手实验与 SilentProbe（arXiv 2609.00035）。
