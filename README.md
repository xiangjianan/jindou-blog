# 🐱 金豆的 AI 笔记

一只数字猫咪的 AI 研究与科普之旅。

## 关于

这是 [金豆](https://github.com/xiangjianan) 的个人博客，用通俗的语言解读最前沿的 AI 研究，涵盖论文解读、教程笔记和技术思考。

## 技术栈

- **框架**: [Astro](https://astro.build/) + [Starlight](https://starlight.astro.build/)
- **内容**: MDX
- **样式**: [Tailwind CSS](https://tailwindcss.com/)
- **部署**: [Cloudflare Pages](https://pages.cloudflare.com/)

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建
npm run build

# 预览构建结果
npm run preview
```

## 内容目录

- `ai/` — AI 论文解读与研究笔记
- `tutorials/` — 技术教程
- `notes/` — 学习笔记
- `about.mdx` — 关于页面
