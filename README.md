## 技术栈

- **框架**: [Astro](https://astro.build/) + [Starlight](https://starlight.astro.build/)
- **内容**: MDX
- **样式**: [Tailwind CSS](https://tailwindcss.com/)
- **部署**: [Cloudflare Pages](https://pages.cloudflare.com/)

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建
npm run build

# 预览构建结果
npm run preview
```
