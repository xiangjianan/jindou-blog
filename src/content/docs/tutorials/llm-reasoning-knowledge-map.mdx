## 一、核心概念

- **推理增强**：通过外部机制提升 LLM 在复杂推理任务（数学、逻辑、规划等）上的表现
- **慢思考 vs 快思考**：类比人类 System 1/2，推理增强旨在让模型进行更深层、更结构化的"慢思考"
- **涌现能力**：推理能力随模型规模增长而涌现，但可通过增强方法在较小模型上也能激发
- **推理差距（Reasoning Gap）**：模型在简单任务上的表现与人类专家级推理之间的差距

## 二、推理增强的分类范式

### 2.1 Prompt-based（提示增强）

通过设计特定的提示模板引导模型进行推理。

- **Zero-shot CoT**（Kojima et al., 2022）：仅添加 "Let's think step by step"
- **Plan-and-Solve**（Wang et al., 2023）：引导先规划再执行
- **Chain-of-Thought (CoT)**（Wei et al., 2022）：逐步推理的经典范式
- **Tree-of-Thought (ToT)**（Yao et al., 2023）：多路径探索与回溯的树状推理
- **Graph-of-Thought (GoT)**（Besta et al., 2023）：图结构推理，支持合并/细化
- **Least-to-Most**（Zhou et al., 2022）：先分解子问题，再逐步解决
- **Self-Refine**（Madaan et al., 2023）：迭代自我改进
- **Reflexion**（Shinn et al., 2023）：基于语言反馈的自我反思

### 2.2 RL-based（强化学习增强）

通过强化学习优化模型的推理策略。

- **DeepSeek-R1 / R1-Zero**：纯 RL 激发推理能力，展示了"顿悟时刻"
- **OpenAI o1 / o3**：推理时计算缩放，o3 在 ARC-AGI 基准上突破 87%
- **Process Reward Models (PRM)**：逐步验证推理过程的正确性
- **STaR**：Self-Taught Reasoner，模型生成推理链后自训练

### 2.3 Self-evolution（自我进化）

模型通过自身生成的数据进行迭代改进。

- **Absolute Zero**：无需外部数据的自我博弈推理框架
- **SPIN**：模型与自身历史版本对弈
- **Quiet-STaR**：让模型在所有 token 上隐式推理
- **ReST**：强化自训练

### 2.4 Neuro-symbolic（神经符号融合）

结合神经网络与符号推理系统。

- **PAL / PoT**：将推理步骤编译为代码执行
- **ReAct**：推理与行动的协同
- **AlphaProof**（DeepMind, 2024）：IMO 级别的数学证明
- **RoG**：知识图谱上的推理框架

### 2.5 推理时缩放（Test-time Compute Scaling）

在推理阶段增加计算量以提升表现。

- **Search/Planning**：ToT, GoT, MCTS 等搜索策略
- **Best-of-N**：采样 N 条推理链，选最优
- **Verifier-guided**：用验证器引导搜索方向

### 2.6 多智能体协作

通过多个 LLM 协作完成复杂推理。

- **Debate**：多模型辩论提升推理
- **Society of Mind**：角色扮演式多智能体
- **CAMEL**：多智能体协作框架

## 五、核心挑战与开放问题

**训练挑战**：奖励模型质量、合成数据污染、推理数据稀缺、训练不稳定性

**推理效率**：长链推理延迟、推理计算开销、计算预算分配

**评估与方法论**：推理 vs 模式匹配的辨别、泛化能力、评估指标局限

**理论理解**：涌现机制、Scaling Laws 适用性、最优推理策略

**开放问题**：
- 能否实现跨领域的通用推理能力？
- 推理时计算的上界在哪里？
- 如何在小模型上实现接近大模型的推理能力？
- 推理增强是否引入新的安全风险？
