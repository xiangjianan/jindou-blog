研究者故意发错参数，然后观察 API 的反应。两种写法，命运天差地别：

约束写在描述文字里 

"description": "请确保 date 为
  ISO 日期格式"
 
// 结果：61 例中 44 例
// API 返回 HTTP 200 + 正常 body
// Agent 完全不知道自己错了
PLAIN ENGLISH

约束被写成了「客气的请求」，不是硬性边界。

模型发错了日期格式，服务端却照样收下。

返回 200 = "成功"？Agent 认为自己做对了。

这就是静默失败：错了，但没人知道。

核心洞察

模型不是不守规矩——是你的 schema 没给它守规矩的机会。约束的形式，决定了 Agent 的可靠性。
